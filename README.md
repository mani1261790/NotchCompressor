# NotchCompressor

画面収録を画面上端のノッチ周辺へドロップして圧縮する、SwiftUI製のmacOSアプリです。

| 左 | 中央 | 右 |
| --- | --- | --- |
| 画質のみ | 画質＋音質 | 音質のみ |
| 音声を保持 | 両方を再エンコード | 映像を保持 |

ファイルのドラッグ中だけパネルを展開し、ドロップした位置でモードを選びます。複数動画をまとめてドロップでき、処理中にも追加できます。圧縮の進捗と結果はメニューバーから確認できます。キュー画面の「＋」からもモードを選んで追加できます。

**圧縮が成功すると元ファイルを置き換えます。** 一時ファイルへ変換して全体のデコード検証を行い、問題がなければ同じ名前・場所に保存します。MOV／MP4／M4Vの拡張子に合ったコンテナを維持します。失敗・キャンセル・元ファイルの変更を検出した場合は置き換えません。置き換え後は圧縮前の動画を残しません。削減率は実測値で、動画によっては容量が増える場合もあります。

## キューの実行方式と並べ替え

- **自動（既定）**: 最大2件。映像圧縮は同時に1件まで、空き枠に音質のみの処理を割り当てます。省電力モード、通常より高い温度状態、8GB未満のメモリまたは4論理CPU未満では、新しく開始する処理を1件までに制限します。
- **1件ずつ / 最大2件**: キュー上部から手動指定できます。方式を変えても、処理中の動画を打ち切りません。
- **ドラッグで並べ替え**: 実行中以外のカードを別の非実行カードへドラッグ＆ドロップすると、挿入位置の線に合わせて順番を変更します。優先度の設定はなく、リストの順番を使います。実行中・停止処理中の動画は先頭に固定し、移動できません。
- **各カードの一時停止 / 再開**: ⏸で途中データと圧縮プロセスを保持し、▶でその続きから再開します。キャンセルや最初からの再変換にはなりません。
- **キューから外す**: 待機中・一時停止中・終了済みのカードは×で個別に外せます。一時停止中の圧縮は終了させ、途中データを破棄してからカードを除外します。元動画は削除しません。

キュー全体を停止する操作はありません。追加した動画は空き枠ができると自動で開始します。

途中から再開できるのはアプリを起動したままの間です。アプリ終了・Mac再起動後は最初からの再試行になります。一時停止中も同じ元動画の排他と実行枠（最大2件）を保持するため、待機動画を開始するには再開または除外してください。

実行できる空き枠がある動画をキューの順に開始するので、映像圧縮や同じファイルを待っている動画を、音質のみの動画が先に処理される場合があります。実行中は開始順で先頭に固定し、それ以外は並べ替えた順に表示します。停止したカードは非実行カードの先頭に残り、手動で並べ替え・除外できます。成功した動画は完了の都度キューから消えます。新しく追加した動画は待機列の末尾に入ります。

同じ元ファイルは、異なる圧縮モードやシンボリックリンク・ハードリンク経由でも同時に処理しません。自動調整は保守的なルールで、処理時間の学習や常に最速の実行を保証するものではありません。実行方式と並び順を保存し、再起動後の未完了処理は従来どおり中断扱いで自動再実行しません。

## 動作環境

- macOS 14以上。初回の配布対象はApple Siliconです。
- FFmpeg / ffprobeをアプリに同梱します。Homebrewなどの追加インストールは不要です。
- 映像の圧縮にはMacのHEVC VideoToolboxエンコーダを使います。

Developer IDの発行待ちのため、署名・公証済みの一般配布版はまだありません。試験版はアドホック署名で、ダウンロード後のGatekeeper検証は未完了です。

## 対応範囲

- ローカルに実体のあるMOV／MP4／M4V
- 動画1トラック、音声0〜1トラック。字幕や追加トラックを含む動画は、黙って削らずエラーにします。
- 映像の圧縮はSDR・8bit・不透明映像。HEVCへ変換し、解像度を維持して最大30fpsにします。
- 音声の圧縮はモノラル／ステレオをAACへ変換します。
- 「音質のみ」で音声がない場合は処理しません。「両方」で音声がない場合は映像だけを処理します。
- 保持する側は再エンコードしません。MOVへ格納できない形式ではエラーにします。
- iCloud上の未ダウンロード動画は、Finderでダウンロードしてから追加してください。

圧縮強度は画質優先／標準／容量優先。設定変更は、変更後に追加したジョブに適用します。再試行も現在の設定を使います。標準の品質値は暫定で、実際の画面収録での可読性・音声評価は未完了です。

## ビルドと起動

Xcode 26以降とmacOS 26以降のSDKが必要です。Xcodeで `Package.swift` を開いて編集できます。

```sh
bash scripts/build-app.sh
open dist/NotchCompressor.app
```

生成物はビルドしたMacのアーキテクチャ向けです。ローカル実行用のアドホック署名を付けています。FFmpeg 9.0.1を固定したソースからビルドし同梱します。初回ビルドにはダウンロードとコンパイルの時間がかかります。Developer ID署名・公証と自動更新は未対応です。

アプリはメニューバーに常駐します。終了はメニューの「NotchCompressorを終了」。処理が残っていれば確認し、キャンセル完了を待って終了します。ログイン時起動は設定から切り替えられます。

## テスト

```sh
# 単体テスト（実メディアのテストはスキップ）
bash scripts/test.sh

# 実FFmpeg / VideoToolboxを使う統合テストも実行
NOTCH_FFMPEG_DIR="$PWD/.build/vendor/install-$(uname -m)/bin" NOTCH_MEDIA_TESTS=1 bash scripts/test.sh
```

XCTestにはフルXcodeを使います。ビルド・テストスクリプトは既定SDKが古い場合、インストール済みの対応Xcodeをコマンド内だけで選びます。システムの `xcode-select` は変更しません。明示した `DEVELOPER_DIR` が優先です。

統合テストは一時フォルダに合成動画を作ります。ユーザーの既存動画は使用しません。3モード、保持側のパケットSHA256一致、同名置き換え、MOV/MP4/M4V、ファイル権限、外部変更時の拒否、破損、無音声、キャンセル時の元データ保持を検証します。

検証結果と未確認の範囲は [docs/VALIDATION.md](docs/VALIDATION.md)、実装計画は [PLAN.md](PLAN.md)、進捗は [GitHub Issues](https://github.com/mani1261790/NotchCompressor/issues) を参照してください。

## 履歴と異常終了

設定と履歴は `~/Library/Application Support/com.mani.NotchCompressor/queue.json` に保存します。直近100件の成功結果は内部履歴として保持しますが、キューには表示しません。終了した項目を消しても動画は削除しません。破損した履歴は上書きせず、保存できないことを画面に表示します。

再起動時、未完了の処理は「前回の処理が中断」と表示し、自動再変換しません。クラッシュや強制終了では、元フォルダに `.notchcompressor-UUID` の一時ディレクトリが残ることがあります。これは完成出力として扱いません。通常のキャンセル・終了では当該ジョブの一時出力を片付けます。

通常時はノッチに重なる黒い小さな領域を表示します。ファイルを上端中央にドラッグすると3領域に広がり、離すと元のサイズに戻ります。ノッチのない画面では180×28ptの小さな領域を表示します。

ビルドにはXcode 26以降（Liquid Glass対応SDK）が必要です。CIではXcode 26.3を明示的に選択します。生成したアプリの最低動作環境はmacOS 14のままで、macOS 26未満では代替の丸いコントロールを使います。
