# NotchCompressor

[製品ページ](https://mani1261790.github.io/NotchCompressor/)

[English](README.en.md)

動画・画像・音声を画面上端のノッチ周辺へドロップして圧縮する、SwiftUI製のmacOSアプリです。

| 左 | 中央 | 右 |
| --- | --- | --- |
| 画質のみ | 画質＋音質 | 音質のみ |
| 音声を保持 | 両方を再エンコード | 映像を保持 |

ファイルをドラッグするとパネルを展開し、ドロップした位置でモードを選びます。複数動画をまとめてドロップでき、処理中にも追加できます。圧縮の進捗と結果はメニューバーから確認できます。キュー画面の「＋」からもモードを選んで追加できます。

**検証に成功し、容量が減った場合だけ元ファイルを置き換えます。** 一時ファイルへ変換して全体をデコード検証し、同じ名前・場所に保存します。MOV／MP4／M4Vのコンテナを維持します。失敗・キャンセル・容量削減なし・元ファイルの変更を検出した場合は置き換えません。置き換え後は圧縮前の動画を残さないため、必要な原本は別途保存してください。

## インストール（Apple Silicon）

macOS 14以降・Apple Siliconに対応しています。

1. [0.2.1のリリース](https://github.com/mani1261790/NotchCompressor/releases/tag/v0.2.1)から `NotchCompressor-0.2.1-arm64-ja.dmg` をダウンロードします。
2. DMGを開き、`NotchCompressor.app` をApplicationsへドラッグします。
3. アプリケーションフォルダから起動します。メニューバーとノッチ周辺に常駐します。

アプリとDMGはDeveloper ID署名・Apple公証済みです。隔離属性を解除するコマンドは不要です。配布物のSHA-256はReleaseの `SHA256SUMS.txt` に掲載しています。

alpha.1には自動更新機能がないため、最新版へはDMGから手動で更新してください。alpha.2以降は設定・メニューバーから更新確認ができます。新規インストールでは自動チェックがオンになります。既存の設定は維持します。

alpha.2で「インストールして再起動」を選んでも終了しない場合は、設定画面を閉じてからメニューの「NotchCompressorを終了」を選んでください。更新が完了すると再起動します。この問題は0.1.0で修正しています。

日本語・英語に対応しています。日英のDMGはインストール案内だけが異なり、アプリ本体は同じです。表示はmacOSのアプリごとの言語設定に従い、変更はアプリの再起動後に反映します。

## 画像・音声とノッチ表示

JPEG・PNG・AAC音声のM4Aも動画とまとめて追加できます。JPEG品質と音声ビットレートは設定で個別に調整します。PNGは画素・透過を保って最適化します。画像は128 MB・32メガピクセルまで。APNG・HEIF・HDR画像、ALAC・WAV・MP3には対応していません。M4Aは単一のモノラル／ステレオAACトラックが対象です。保持できないメタデータ等がある場合は原本を残します。

ノッチにカーソルを合わせると時計やApple Musicの曲名・アルバム画像を表示し、再生・一時停止を操作できます。時計と音楽は、それぞれ非表示・ホバー時・常時表示を選べます。Musicの操作権限は接続時に確認します。

## フレームレート

新規設定では元のfpsを維持し、設定から「最大30fps」も選べます。「元のfpsを維持」は可変fpsのタイミングを保ち、「最大30fps」は一定の間隔に揃えます。既存ユーザーの設定と投入済みタスクは従来の動作を保持します。映像をコピーする音質のみモードには影響しません。

検証済みの環境と未確認の範囲は[検証記録](docs/VALIDATION.md)を参照してください。品質と容量の変化は素材に依存します。

## 圧縮を事前に設定する

設定の「品質と容量」で「カスタム」を選ぶと、映像は元のビットレートの10〜100%を1%刻み、音声は32〜256 kbpsを8 kbps刻みで指定できます。たとえば映像50%・音声80 kbps。従来の品質優先・標準・容量優先も利用できます。

数値は自動保存され、次に追加する動画から適用します。追加済みの動画は投入時の設定を保持し、カードに適用値を表示します。画質のみでは音声を、音質のみでは映像をそのまま保持します。

映像50%はファイル容量50%の保証ではありません。映像の元ビットレートが不明な場合は容量・長さから推定します。目標映像ビットレートは32 kbps〜100 Mbps、音声は元音声を上限（最低32 kbps）に調整します。実容量は内容や保持するトラックによって変わります。

### プリセットと圧縮方法の違い

プリセットは音声のみ・映像のみ・両方のいずれにも適用します。選んだ対象に対応する設定だけを使います。

| プリセット | 映像の自動調整で使う上限の目安 | 音声の目標 |
| --- | --- | --- |
| 品質優先 | 元ビットレートの85% | AAC 128 kbps |
| 標準 | 元ビットレートの65% | AAC 96 kbps |
| 容量優先 | 元ビットレートの45% | AAC 64 kbps |

映像は解像度×選択した出力fps×係数（順に0.09/0.06/0.035）で求めた値と元の割合を比べ、小さい方を150 kbps〜12 Mbpsに収めます。割合はファイル容量の削減率ではありません。音声は元のビットレートを上限（最低32 kbps）に調整します。

変換方式は全プリセット共通で、映像はHEVC（H.265）のハードウェア変換、音声はAACです。映像を再圧縮するときは解像度を維持し、fpsは設定で維持または最大30fpsを選べます。対象外のトラックは再圧縮せずコピーします。カスタムだけは映像の自動算出を使わず、指定した元ビットレートの割合を目標にします。

### 映像の処理速度

設定の「処理速度」で「速度優先」を選ぶと、HEVCハードウェアエンコーダへ速度優先を指定します。既定は従来の「標準」です。同じ目標ビットレートでも画質や圧縮効率が変わる場合があり、対応していない環境では効果がありません。次に追加する動画の「画質のみ」「画質＋音質」に適用し、「音質のみ」や出力検証には影響しません。

M2での合成動画では圧縮時間が約36%短縮しましたが、実際の画面収録や別のMacでの改善幅は未確認です。[測定条件と画質の比較](docs/PERFORMANCE.md)を参照してください。

## キューの実行方式と並べ替え

- **自動（既定）**: 最大2件。映像圧縮は同時に1件まで、空き枠に音質のみの処理を割り当てます。省電力モード、通常より高い温度状態、8GB未満のメモリまたは4論理CPU未満では、新しく開始する処理を1件までに制限します。
- **1件ずつ / 最大2件**: キュー上部から手動指定できます。方式を変えても、処理中の動画を打ち切りません。
- **ドラッグで並べ替え**: 実行中以外のカードを別の非実行カードへドラッグ＆ドロップすると、挿入位置の線に合わせて順番を変更します。優先度の設定はなく、リストの順番を使います。実行中・停止処理中の動画は先頭に固定し、移動できません。
- **各カードの一時停止 / 再開**: ⏸で途中データと圧縮プロセスを保持し、▶でその続きから再開します。キャンセルや最初からの再変換にはなりません。
- **キューから外す**: 待機中・一時停止中・終了済みのカードは×で個別に外せます。一時停止中の圧縮は終了させ、途中データを破棄してからカードを除外します。元動画は削除しません。

キュー全体を停止する操作はありません。追加した動画は空き枠ができると自動で開始します。

途中から再開できるのはアプリを起動したままの間です。アプリ終了・Mac再起動後は最初からの再試行になります。一時停止中も同じ元動画の排他と実行枠（最大2件）を保持するため、待機動画を開始するには再開または除外してください。

実行できる空き枠がある動画をキューの順に開始するので、映像圧縮や同じファイルを待っている動画を、音質のみの動画が先に処理される場合があります。実行中は開始順で先頭に固定し、それ以外は並べ替えた順に表示します。停止したカードは非実行カードの先頭に残り、手動で並べ替え・除外できます。成功した動画は完了の都度キューから消えます。新しく追加した動画は待機列の末尾に入ります。

同じ元ファイルは、異なる圧縮モードやシンボリックリンク・ハードリンク経由でも同時に処理しません。自動調整は保守的なルールで、処理時間の学習や常に最速の実行を保証するものではありません。実行方式と並び順を保存し、再起動後の未完了処理は従来どおり中断扱いで自動再実行しません。

## 動作環境

- macOS 14以上。初回の配布対象はApple Siliconです。
- FFmpeg / ffprobeをアプリに同梱します。Homebrewなどの追加インストールは不要です。
- 映像の圧縮にはMacのHEVC VideoToolboxエンコーダを使います。

## 対応範囲

- ローカルに実体のあるMOV／MP4／M4V
- 動画1トラック、音声0〜1トラック。字幕や追加トラックを含む動画は、黙って削らずエラーにします。
- 映像の圧縮はSDR・8bit・不透明映像。HEVCへ変換し、解像度を維持します。fpsは設定で維持または最大30fpsを選べます。
- 音声の圧縮はモノラル／ステレオをAACへ変換します。
- 「音質のみ」で音声がない場合は処理しません。「両方」で音声がない場合は映像だけを処理します。
- 保持する側は再エンコードしません。元のコンテナへ格納できない形式ではエラーにします。
- iCloud上の未ダウンロード動画は、Finderでダウンロードしてから追加してください。

品質と容量は品質優先／標準／容量優先／カスタムから選べます。設定変更は、変更後に追加したジョブに適用します。再試行も現在の設定を使います。標準の品質値は暫定で、実際の画面収録での可読性・音声評価は未完了です。

## ビルドと起動

Xcode 26以降とmacOS 26以降のSDKが必要です。Xcodeで `Package.swift` を開いて編集できます。

```sh
bash scripts/build-app.sh
open dist/NotchCompressor.app
```

生成物はビルドしたMacのアーキテクチャ向けです。ローカル実行用のアドホック署名を付けています。FFmpeg 9.0.1を固定したソースからビルドし同梱します。初回ビルドにはダウンロードとコンパイルの時間がかかります。Developer ID配布用の手順は[配布ガイド](docs/DEVELOPER_ID_RELEASE.md)を参照してください。配布版の更新確認にはSparkleを使います。

アプリはメニューバーに常駐します。終了はメニューの「NotchCompressorを終了」。処理が残っていれば確認し、キャンセル完了を待って終了します。ログイン時起動は設定から切り替えられます。

## ショートカット・結果・診断

設定の「ショートカット」で「圧縮キューを開く」に好きなキーを登録できます。初期状態は未設定で、記録欄の×から解除できます。他のアプリからキューを開くための操作で、圧縮を自動で開始しません。

メニューバーは実行中・一時停止・要確認の状態をアイコンと件数で表示します。完了した動画はキューから消え、直近の完了件数と容量差を8秒間表示します。続けて完了した場合はまとめて表示し、容量が減らなかった場合は元動画を保持したことを表示します。

設定の「サポート」から診断情報を確認してコピーできます。動画名・パス・生ログを含まず、外部へ自動送信しません。報告に貼り付ける前に内容を確認できます。

### コードの整形

`bash scripts/format.sh write` で整形し、`bash scripts/format.sh check` で検査します。Xcode同梱のswift-formatと `.swift-format` を使い、CIでも検査します。機能変更と全体の整形は別コミットにしてください。

## テスト

```sh
# 単体テスト（実メディアのテストはスキップ）
bash scripts/test.sh

# 実FFmpeg / VideoToolboxを使う統合テストも実行
NOTCH_FFMPEG_DIR="$PWD/.build/vendor/install-$(uname -m)/bin" NOTCH_MEDIA_TESTS=1 bash scripts/test.sh
```

XCTestにはフルXcodeを使います。ビルド・テストスクリプトは既定SDKが古い場合、インストール済みの対応Xcodeをコマンド内だけで選びます。システムの `xcode-select` は変更しません。明示した `DEVELOPER_DIR` が優先です。

統合テストは一時フォルダに合成動画を作ります。ユーザーの既存動画は使用しません。3モード、保持側のパケットSHA256一致、同名置き換え、MOV/MP4/M4V、ファイル権限、外部変更時の拒否、破損、無音声、キャンセル時の元データ保持を検証します。

検証結果と未確認の範囲は [docs/VALIDATION.md](docs/VALIDATION.md)、実装計画は [PLAN.md](PLAN.md)、進捗は [GitHub Issues](https://github.com/mani1261790/NotchCompressor/issues) を参照してください。

## 履歴と異常終了

設定と履歴は `~/Library/Application Support/com.mani.NotchCompressor/queue.json` に保存します。直近100件の成功結果は内部履歴として保持しますが、キューには表示しません。終了した項目を消しても動画は削除しません。破損した履歴は上書きせず、保存できないことを画面に表示します。

再起動時、未完了の処理は「前回の処理が中断」と表示し、自動再変換しません。クラッシュや強制終了では、元フォルダに `.notchcompressor-UUID` の一時ディレクトリが残ることがあります。これは完成出力として扱いません。通常のキャンセル・終了では当該ジョブの一時出力を片付けます。

通常時はノッチに重なる黒い小さな領域を表示します。ファイルを上端中央にドラッグすると3領域に広がり、離すと元のサイズに戻ります。ノッチのない画面では180×28ptの小さな領域を表示します。

ビルドにはXcode 26以降（Liquid Glass対応SDK）が必要です。CIではXcode 26.3を明示的に選択します。生成したアプリの最低動作環境はmacOS 14のままで、macOS 26未満では代替の丸いコントロールを使います。

## ログイン起動・完了と失敗の通知

設定の「起動」→「Macへのログイン時に起動」を有効にすると、次のログインから常駐します。承認待ちの場合は「ログイン項目を確認」からmacOS側で許可してください。Macの電源投入直後ではなく、ユーザーのログイン時に起動します。システム設定からアプリへ戻った際に状態を再確認します。

設定の「通知」→「圧縮の完了・失敗を通知」をオンにし、macOSの通知を許可すると、完了時は実測の「圧縮前 → 圧縮後」と容量差、失敗時は対処方法を通知します。通知をクリックするとキューが開きます。通知機能は初期状態でオンですが、送信にはmacOSでの許可が必要です。動画名やパスは含みません。キャンセルと過去の履歴は通知しません。集中モードなどでバナーが表示されない場合も、キューで結果を確認できます。

容量不足の場合は、キューの「外付けディスクを使う」から一時的な作業場所を選べます。候補の空き容量を確認してから表示し、別の場所も選択できます。正常終了後は作業ファイルと復旧記録を削除し、ディスクの選択履歴は保存しません。作業中は外付けディスクを接続したままにしてください。

省容量モードでは、原本を外付けに退避してから圧縮結果を元の場所へ戻します。中断時は元の場所にファイルがなく、外付けに原本が残っていることがあります。その場合は外付けを接続してキューから復旧し、退避フォルダを手動で削除しないでください。通常の未完了タスクの再試行とは別の操作です。


### バックグラウンドでの圧縮

他のアプリへの切り替え、キュー画面を閉じる操作、画面の消灯やロックだけでは圧縮を中止しません。実行中（解析・変換・検証・終了処理）はApp Napとアイドル時の自動スリープを抑止し、画面の消灯は妨げません。すべて一時停止したときと、処理が終わったときはこの制御を解除します。

スリープ前に実行中の処理を一時停止し、復帰後はスリープによる停止だけを解除します。手動で停止したタスクは停止を保ちます。保存先への接続が失われた場合などは原本を保持し、対処方法を表示します。ログアウト・Mac再起動・アプリ終了後は途中から再開せず、未完了タスクを最初から再試行します。通常の終了操作では、処理が残っていれば確認を表示します。
