# NotchCompressor

画面収録をノッチ周辺へのドロップで圧縮する、SwiftUI製のmacOSアプリ。

## 現在の状態

**操作プロトタイプです。圧縮処理はまだ実装していません。**

- ファイルを画面上端中央へドラッグすると3つのドロップ領域を表示。
- 左「画質のみ」、中央「画質＋音質」、右「音質のみ」。
- 受け取ったファイル名と選択モードをメニューバーに表示。
- 元ファイルへの書き込み、移動、削除は行いません。

SwiftUIで表示を構成し、AppKitのNSPanelでノッチ周辺へ配置しています。ドラッグ検知の実機検証、展開アニメーション、圧縮処理は今後の作業です。ノッチ本体ではなく、その直下に中央のドロップ領域を配置します。

## 開発

- macOS 14以上
- Swift 5.10以上（XcodeまたはCommand Line Tools）
- 外部パッケージ依存なし

```sh
swift build
bash scripts/build-app.sh
open dist/NotchCompressor.app
```

Xcodeでは`Package.swift`を開いて編集できます。アプリはメニューバーに常駐し、メニューの「終了」で終了できます。生成したアプリはローカル実行用のアドホック署名です。配布用署名・公証は未設定です。

仕様と実装順は[PLAN.md](PLAN.md)を参照してください。
