# NotchCompressor

画面収録を画面上端のノッチ周辺へドロップして圧縮する、SwiftUI製のmacOSアプリです。

| 左 | 中央 | 右 |
| --- | --- | --- |
| 画質のみ | 画質＋音質 | 音質のみ |
| 音声を保持 | 両方を再エンコード | 映像を保持 |

ファイルのドラッグ中だけパネルを展開し、ドロップした位置でモードを選びます。複数動画は順番に処理します。圧縮の進捗と結果はメニューバーから確認できます。キュー画面の「動画を選ぶ…」からもモードを選んで追加できます。

**元ファイルは削除しません。** 同じフォルダへ別名のMOVを作り、全体のデコード検証後に保存します。削減率は実測値で、動画によっては大きくなります。元を残す間は空き容量は増えません。結果を確認してからFinderで整理してください。

## 必要なもの

- macOS 14以上
- 同じMacにインストールした `ffmpeg` と `ffprobe`
- 映像を変換する場合はHEVC VideoToolboxエンコーダを利用できるFFmpegとMac

Apple Siliconの `/opt/homebrew/bin` とIntel Macの `/usr/local/bin` を自動探索します。別の場所はアプリの設定から選択できます。FFmpegをアプリへ同梱していません。Homebrewを利用している場合の導入コマンドは次のとおりです。

```sh
brew install ffmpeg
```

不足している場合、アプリの設定画面に必要なツールとフォルダ選択ボタンを表示します。

## 対応範囲

- ローカルに実体のあるMOV／MP4／M4V
- 動画1トラック、音声0〜1トラック。字幕や追加トラックを含む動画は、黙って削らずエラーにします。
- 映像の圧縮はSDR・8bit・不透明映像。HEVCへ変換し、解像度を維持して最大30fpsにします。
- 音声の圧縮はモノラル／ステレオをAACへ変換します。
- 「音質のみ」で音声がない場合は処理しません。「両方」で音声がない場合は映像だけを処理します。
- 保持する側は再エンコードしません。MOVへ格納できない形式ではエラーにします。
- iCloud上の未ダウンロード動画は、Finderでダウンロードしてから追加してください。

圧縮強度は画質優先／標準／容量優先。設定変更は、変更後に追加したジョブに適用します。再試行も現在の設定を使います。標準の品質値は暫定で、実際の画面収録での可読性・音声評価は未完了です。

## ビルドと起動

Swift 5.10以上とmacOS SDKが必要です。Xcodeで `Package.swift` を開いて編集できます。

```sh
bash scripts/build-app.sh
open dist/NotchCompressor.app
```

生成物はビルドしたMacのアーキテクチャ向けです。ローカル実行用のアドホック署名を付けています。Developer ID署名・公証・第三者バイナリ同梱・自動更新は未対応です。

アプリはメニューバーに常駐します。終了はメニューの「NotchCompressorを終了」。処理が残っていれば確認し、キャンセル完了を待って終了します。ログイン時起動は設定から切り替えられます。

## テスト

```sh
# 単体テスト（実メディアのテストはスキップ）
bash scripts/test.sh

# 実FFmpeg / VideoToolboxを使う統合テストも実行
NOTCH_MEDIA_TESTS=1 bash scripts/test.sh
```

XCTestにはフルXcodeを使います。`test.sh` は既定がCommand Line Toolsの場合、インストール済みのXcodeをこのコマンドだけ指定します。システムの `xcode-select` は変更しません。明示した `DEVELOPER_DIR` が優先です。

統合テストは一時フォルダに合成動画を作ります。ユーザーの既存動画は使用しません。3モード、保持側のパケットSHA256一致、元ファイル不変、破損、無音声、出力名衝突、キャンセルを検証します。

検証結果と未確認の範囲は [docs/VALIDATION.md](docs/VALIDATION.md)、実装計画は [PLAN.md](PLAN.md)、進捗は [GitHub Issues](https://github.com/mani1261790/NotchCompressor/issues) を参照してください。

## 履歴と異常終了

設定と履歴は `~/Library/Application Support/com.mani.NotchCompressor/queue.json` に保存します。直近の完了履歴を保持し、履歴を消しても動画は削除しません。破損した履歴は上書きせず、保存できないことを画面に表示します。

再起動時、未完了の処理は「前回の処理が中断」と表示し、自動再変換しません。クラッシュや強制終了では、元フォルダに `.notchcompressor-UUID` の一時ディレクトリが残ることがあります。これは完成出力として扱いません。通常のキャンセル・終了では当該ジョブの一時出力を片付けます。

通常時はノッチに重なる黒い小さな領域を表示します。ファイルを上端中央にドラッグすると3領域に広がり、離すと元のサイズに戻ります。ノッチのない画面では180×28ptの小さな領域を表示します。
