# v0.1.0-alpha.1 — 初期試験版

画面収録をノッチ周辺へドラッグして圧縮するmacOSアプリです。Apple Silicon・macOS 14以上に対応します。

## ダウンロードと起動

`NotchCompressor-0.1.0-alpha.1-arm64.zip` を展開し、アプリを「アプリケーション」へ移動してください。FFmpeg / ffprobeは同梱済みです。

Developer ID署名・Appleの公証はありません。初回起動時は「システム設定 → プライバシーとセキュリティ → このまま開く」から許可してください。公式Releaseから取得したアプリに限り、次の方法でも隔離属性を解除できます。

```sh
xattr -dr com.apple.quarantine "/Applications/NotchCompressor.app"
```

[インストール手順](https://github.com/mani1261790/NotchCompressor#インストールapple-silicon-試験版) / [Appleの案内](https://support.apple.com/ja-jp/102445)

## 主な機能

- 左で映像のみ、中央で映像と音声、右で音声のみを圧縮。対象外のトラックはそのまま保持。
- 複数動画の投入、自動/直列/最大2件の実行、ドラッグによる順序変更。
- 各タスクの一時停止・途中再開・個別除外。途中再開はアプリを開いたままの間に対応。
- 品質プリセットと、映像の割合・音声kbpsを事前指定するカスタム設定。
- Liquid Glass対応UIとファイルごとのサムネイル。

**圧縮成功時は、検証してから元動画を同じ名前・場所で上書きします。圧縮前の動画は残りません。** 必要な原本はコピーを保管してから試してください。失敗・キャンセル時は元動画を保持します。実容量は動画によって変わり、増える場合もあります。

## 検証と既知の制限

49件の自動テストと最新コードのCIが成功。実アプリのキュー操作・設定・途中再開、合成動画による実変換と出力検証を確認しています。

- Mission Control対策後のFinderからのドロップ完了は追加確認待ち。
- 追加画面構成・フルスクリーン・ログイン起動の実機確認には未完了の範囲があります。
- 代表的な画面収録の文字・音声品質評価は未完了。
- ダウンロード後の初回起動経路は未検証。Intel、自動更新、終了/再起動をまたぐ途中再開は未対応。

これらを既知の制限として公開する初期試験版です。Developer ID取得後に署名・公証版を準備します。
