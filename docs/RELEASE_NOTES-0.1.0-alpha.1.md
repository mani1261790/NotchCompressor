# 0.1.0-alpha.1 — Apple Silicon 試験版

画面上端へ動画をドラッグし、左で画質、中央で画質と音質、右で音質を圧縮します。圧縮キュー、キャンセル、再試行、履歴、Liquid Glass対応の設定を備えます。

**成功すると元動画を同じ名前・場所で置き換えます。圧縮前の動画は残りません。** 失敗・キャンセル時は元動画を保持します。画質・音質を変更した部分は非可逆です。サイズが増える場合もあります。

- macOS 14以上、Apple Silicon。FFmpeg 9.0.1 / ffprobe内包、追加インストール不要。
- アプリ本体: Apache 2.0。FFmpeg: LGPL 2.1以降。対応ソースとビルド情報を同じReleaseに添付。
- Developer ID申請中のため、アドホック署名のみ。Appleによる公証はなく、ダウンロード後のGatekeeper確認は未実施です。一般配布の完成版ではありません。

## 検証

同梱したFFmpegを使って27テスト成功（スキップ0）。3モードの実変換、保持側のpacket SHA-256、MOV/MP4/M4Vの同名置き換え、外部変更拒否、権限、キャンセル時の元データ保持を合成動画で確認。アプリと同梱実行ファイルの署名整合性、外部Homebrewライブラリへの依存がないことを確認。
