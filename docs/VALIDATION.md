## 手動確認の手順

1. `.app` を起動。メニューバーから圧縮キューと設定が開けることを確認。
2. テスト用のMOV/MP4をFinderで選び、通常のマウス移動だけではパネルが開かないことを確認。
3. ファイルを上端中央へドラッグし、ノッチにつながって展開することを確認。
4. 左・中央・右へ別々にドロップし、キューのモードと出力が一致することを確認。
5. 離脱・Escではキューに追加されず閉じることを確認。
6. 複数ファイル、音声なしの音質のみ、処理中キャンセル、終了して継続／中止を確認。
7. 元ファイルが残り、出力をFinderで開いて再生できることを確認。

成功・失敗、使った画面、対象ファイルの音声有無をIssueへ記録する。未確認の項目をチェック済みにしない。

## 追加のネイティブ確認

- キューの「動画を選ぶ…」→「画質＋音質」→NSOpenPanelのパス指定→Openから、実際の変換を開始。
- 合成8秒動画: 完了、6.2 MB→1.8 MB、71%削減をSwiftUI画面で確認。出力のffprobe duration=8.000000、size=1799602。
- 「圧縮した動画を表示」でFinderに正しい出力を選択表示。
- 合成120秒動画: 93.2 MB→26.7 MB、71%削減。再起動後も完了履歴を復元。
- 合成1200秒動画: ⌘Qで確認ダイアログ→「処理を続ける」で7%の処理へ復帰→再度⌘Q→「中止して終了」→13%で停止中表示→終了。
- 停止後、履歴がcancelled、元動画932121857 bytesが存在、ジョブの一時ディレクトリなし、確定出力なし、FFmpeg子プロセスなしを確認。
- テストで使用した動画はすべて `.build/manual-fixtures` 内に生成。利用者の既存収録は使用していない。

この終了確認は⌘Qの実経路の証拠。未操作のメニューバー終了やOSログアウトを同等の確認済みとして扱わない。
