macOS 14以降・Apple Silicon向けの試験版です。Developer ID署名・Apple公証済みのDMGからインストールできます。

## インストール

`NotchCompressor-0.1.0-alpha.2-arm64.dmg` を開き、アプリをApplicationsへドラッグして起動してください。隔離属性を解除するコマンドは不要です。alpha.1からの移行もDMGで行ってください。

## 追加・改善

- ログイン時の自動起動と、macOS側の承認待ち状態の案内。
- 完了時の圧縮前後サイズ・容量差と、失敗時の対処方法を知らせる任意の通知。
- 容量不足時の必要な空きの目安・不足量と具体的な対処案内。
- バックグラウンドでの圧縮中にApp Napとアイドルスリープを抑止。全件一時停止・終了時は解除。
- 任意の映像「速度優先」設定。画質とのトレードオフがあり、既定は従来の標準設定を維持。
- キューを開くカスタムショートカット、メニューバーの状態表示、診断情報のプレビュー。
- ApplicationsへドラッグしてインストールするDMGと、Sparkle更新機構。

## 利用上の注意

圧縮成功後は元動画を同名で置き換えます。全体デコード検証と元動画の変更検査を通過するまでは置き換えません。新しい版を試す際は、重要な動画のコピーを用意してください。

速度優先の短縮幅はMacや動画によって異なります。M2の合成動画で約36%短縮しましたが、画質指標は低下しました。実際の画面収録の速度・可読性評価は継続中です。

ウィンドウを閉じても処理は続きますが、ふたを閉じる操作・手動スリープ・ログアウト・アプリ終了後の継続は保証しません。

alpha.1にはSparkleがないため、最初の対応版は手動インストールが必要です。
