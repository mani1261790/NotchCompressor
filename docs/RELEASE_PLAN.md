## 公開前の順序

1. **FFmpeg / ffprobeの同梱（#8）**
   - 配布用バージョンとビルド構成を固定し、外部Homebrewに依存しない成果物を作る。
   - 依存ライブラリ、対応アーキテクチャ、ライセンス表記、対応ソース配布を揃える。
   - アプリ内ツールを通常経路とし、一般ユーザー向けのツール検出/フォルダー指定を撤去。
   - 外部FFmpegのない環境で変換を検証。
2. **代表操作の最終確認（#4/#5/#6/#7）**
   - Mission Control対策後にFinder→各領域→圧縮→同名置き換えを確認。
   - キャンセル、複数ファイル、メニューバーからの操作、ノッチ付き画面、フルスクリーン、ログイン起動を確認。
   - 細かい文字や音声を含む、利用が許可された代表サンプルのコピーで品質を確認。提供された不具合録画を無断で公開しない。
   - 利用できない環境は明記し、確認済みとしない。
3. **配布パッケージ（#8）**
   - アプリのアイコン、バージョン表示、配布アーカイブ、チェックサム、リリースノート。
   - Developer ID署名と公証は発行後に実施。現段階の成果物はアドホック署名の試験版と明示する。ダウンロードしたアプリのGatekeeper確認は未実施。
   - 現在このMacの有効なDeveloper ID Application identityは0件。署名設定が別途必要。
4. **公開内容の点検とPublic化**
   - アプリ本体のライセンスを決定、第三者ライセンスとFFmpeg対応ソースを確認。
   - Git履歴・Issues・添付物を含め、秘密情報や不要な個人情報が公開されないことを点検。
   - 公開向けREADME、対応OS/CPU、上書き動作と既知の制限を明記。
   - 全条件の確認後にリポジトリをPublicへ変更し、検証した同じ成果物をGitHub Releaseに掲載。

## 公開の区別

ソース公開、ローカルアプリのビルド成功、署名・公証済みの一般配布は別の状態。未署名の試験版を一般向け完成版と表示しない。自動更新は初回リリースの必須条件にはしない。
