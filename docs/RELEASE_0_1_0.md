## LP

`site/index.html` と `site/en.html`。Lunamoの配色、余白、書体の構成、外観・言語切替を継承し、独立した静的ページとして管理。MITライセンス表示を同梱。ノッチの操作図は説明用であり、実アプリのスクリーンショットではない。動画をアップロードする機能はない。

GitHub Pagesの配布設定は `.github/workflows/pages.yml`。正式版の公開確認までは、ダウンロード導線を公開済みalpha.2のDMGに固定し、試験版かつ日本語UIであることを記載する。正式版公開後は両言語のダウンロード先、バージョン、保存・スリープ・言語対応の説明をまとめて更新する。
