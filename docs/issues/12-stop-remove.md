## 仕様

- 実行中・停止処理中のカードはキュー先頭に固定し、並べ替え・個別除外・一括除外を拒否する。
- それ以外の表示カード（待機、停止済み、失敗、中断）はドラッグで並べ替え、個別にキューから外せる。動画ファイルは削除しない。
- 実行中のカードは個別の停止ボタンを表示。停止完了後に除外ボタンへ切り替える。
- 「すべて停止」は実行中を停止し、新しい処理の開始も止める。待機動画は保持する。従来の待機一時停止とは区別する。
- 成功したカードの自動除外と同一ファイルの同時処理禁止を維持する。

## 検証

- [x] 順序・停止中の拒否・停止後の除外・待機/失敗/中断の除外と永続化
- [x] 全停止で実行workerが終了し、待機を開始しない
- [x] 個別停止が他の実行workerを止めない
- [x] 実アプリの停止→除外、先頭固定と操作表示
