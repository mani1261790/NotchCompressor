## 混在入力とキュー

- [ ] FinderからJPEG・PNG・AAC M4A・MOVをまとめてノッチへ投入し、種類ごとのアイコン・設定・結果を確認する。
- [ ] 非対応ファイルを混ぜても対応分は開始され、拒否理由が個別に読める。
- [ ] 連続投入でも先行ファイルの処理を妨げず、待機行のみgrabカーソルで並べ替えられる。
- [ ] 画像・音声の処理を個別停止し、行が先頭に残る。再開は同じプロセスの続きから行われる。
- [ ] 実行中の行は除外できず、停止後は除外できる。完了行だけが順に消える。
- [ ] 品質設定を変更しても、追加済みの行は投入時の設定を維持する。
- [ ] 完了・失敗通知と削減前後のサイズを実表示で確認する。
- [ ] 容量不足で原本が残り、空き容量を増やす案内が読める。実ディスクを埋めず、隔離した小容量試験ボリュームを使う。

## ノッチと任意表示

- [ ] 時計・音楽がオフの待機時に黒い背景もクリック領域も残らない。
- [ ] ノッチ中央・左右へのドラッグで展開し、カメラで選択肢が隠れない。Mission Controlを誘発しない。
- [ ] ドラッグ取消時に閉じる。連続した出入りでもパネルが残留しない。
- [ ] Reduce Motion有効時は移動アニメーションを抑える。
- [ ] ノッチのある内蔵画面とノッチのない外部画面で位置・余白を確認する。
- [ ] 時計と日付は任意で表示され、設定オフで消える。
- [ ] 音楽オフ・Music未起動ではMusicを起動せず、権限要求も出さない。
- [ ] 利用者の接続操作時だけMusicの許可要求が出る。許可・拒否・曲なし・曲切替・停止の表示を確認する。
- [ ] 曲名と時計がカメラを避け、長い曲名でもドロップ領域を塞がない。
