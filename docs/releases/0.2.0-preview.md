# 0.2.0 開発版の確認範囲

未公開。0.1.0の対応形式や配布物を変更したものではない。

- JPEG、PNG、AAC音声のM4Aを追加。動画・画像・音声の混在入力を分類し、非対応理由を表示する。
- JPEG品質と単体音声のビットレートを動画とは別に設定。追加済みファイルの設定は維持する。
- 同形式のまま小さくなり検証に通った場合だけ置換。PNGの画素・透過、JPEGの撮影情報、音声のチャンネル・タグ・カバーを保持する。保持できない構成は元を残す。
- 画像の上限は128 MB・32メガピクセル。APNG、複数画像、HDRゲインマップ等、HEIFの再圧縮は未対応。
- 音声は単一mono/stereo AACトラックと最大1枚のJPEG/PNGカバーを持つM4A。ALAC・WAV・MP3等を無設定で非可逆化しない。未知タグ等を保持できない場合も置換しない。
- 待機背景をなくし、ドラッグ時に展開。任意の時計とApple Music曲名表示。Spotify・ブラウザ等の統合は含まない。

実画面・権限の確認と公証済みパッケージ検証後に、公開する内容を確定する。詳細は [実装記録](../design/POST_RELEASE_IMPLEMENTATION.md)。
