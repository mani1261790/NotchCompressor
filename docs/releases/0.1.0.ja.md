# NotchCompressor 0.1.0

画面収録をノッチへドロップして圧縮するmacOSアプリの初回正式版です。

## ダウンロード

macOS 14以降・Apple Siliconに対応。日本語の案内は `-ja.dmg`、英語の案内は `-en.dmg` を選び、アプリをApplicationsへドラッグしてください。両DMGに入っているアプリは同一で、日本語・英語に対応します。アプリとDMGはDeveloper ID署名・Apple公証済みです。

## 主な変更

- 複数動画の追加、待機キューの並べ替え、タスクごとの一時停止・再開と除外。
- 見やすいキューと設定画面、日本語・英語のUIと通知。
- 容量が減り、出力全体の検証に成功した場合だけ元動画を置き換え。失敗・取消・削減なしでは原本を保持。
- スリープから復帰すると処理を再開。手動で止めたタスクは停止状態を保持。
- 元のfpsを維持する設定と最大30fpsの選択。既存設定と投入済みタスクの設定は維持。
- Sparkleによる更新確認と配信。ハードウェアHEVCが既定です。

**置き換え後は圧縮前の動画は残りません。** 必要な原本は別に保存してください。対象はMOV・MP4・M4V動画です。

## 更新と確認範囲

alpha.1はDMGで手動更新してください。alpha.2で更新後に再起動しない場合は設定を閉じ、メニューからアプリを終了してください。0.1.0ではこの問題を修正しています。

ビルド11、ソース `d5a8753`。署名・公証、CI、配布物の照合を実施済みです。再ログイン後の起動、通知バナーの目視、新UIのマウスでの並べ替え確定、追加ディスプレイなどには未確認の範囲があります。画面収録全般での最適な品質は保証せず、引き続き検証します。
