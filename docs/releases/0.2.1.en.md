# NotchCompressor 0.2.1

- When space is low, choose an external disk as a temporary workspace. Available space is checked before disks are offered, and you can choose another location.
- Compressed output is verified on the external disk, then the original is backed up before the smaller file is returned to its original location. No workspace preference or selection history is saved. Temporary files and recovery records are removed on successful completion; interrupted work can be recovered from the queue.
- Fixed the notch expanding on hover when both the clock and music widgets are disabled and no file is being dragged.

Keep the external disk connected until work completes. Space requirements are estimates. If snapshots or other storage use prevent space from being reclaimed, the original remains on the external disk awaiting recovery. Automatic recovery does not support moved source folders or changed disk mount locations.

This release passed 119 automated tests, including real media processing and cross-volume installation using a disk image. Permission dialogs and disconnect/reconnect behavior with a physical external disk have not yet been tested.

Requires Apple Silicon and macOS 14 or later. Japanese and English DMGs contain the same app.
