# 次版のリリース案内（草稿・未公開）

[English](next.en.md)

この案内は開発中の変更をまとめたものです。バージョン番号とダウンロードリンクは、配布検証が完了してから確定します。現在の公開版はalpha.2です。

- 圧縮後の容量が減らなければ、元動画を保持して正常終了します。削減なしであることを通知と結果に表示します。
- スリープによる一時停止と手動の一時停止を区別します。復帰しても手動停止したタスクは再開しません。
- 元のフレームレートを維持する設定と、最大30fpsにする設定を選べます。新規設定は元のfpsを維持し、既存設定・投入済みタスクは従来の動作を保ちます。
- 日本語・英語の表示に対応します。通常操作、通知、失敗理由、履歴の説明を選択言語に揃えます。生の技術ログやファイル名は翻訳しません。
- 日本語用・英語用のDMGを用意します。アプリ本体は同じで、表示言語はmacOSの設定に従います。

ハードウェアHEVCが引き続き既定です。実収録での品質比較が未完了のため、コーデックや速度優先を新たに既定化していません。動画以外の圧縮は今回の対象外です。

## 公開前に残っている確認

実Macの圧縮中・検証中のスリープ復帰、修正版からのSparkle自動更新・再起動を確認しました。ビルド9のアプリと日英DMGは署名・公証済みです。言語切替修正とFinderから中央への単一動画ドロップも確認済みです。通知バナー、再ログイン時の起動、停止中などの更新延期、実収録の品質評価が残っています。公開後には配布物を匿名ダウンロードして照合します。

alpha.2からの更新では、設定画面が再起動を妨げる場合があります。今回の版では修正していますが、旧版の更新手順は公開前に確認・案内します。

## 保存について

容量が減り、出力全体の検証に成功した場合は元動画を置き換えます。置き換え後に圧縮前の動画は残りません。失敗・取消・容量削減なしの場合は元動画を保持します。
