# NotchCompressor 0.2.1

- 空き容量が足りないとき、外付けディスクを一時的な作業場所として選べるようになりました。容量を確認してから候補を表示し、別の場所にも変更できます。
- 外付けで圧縮結果を検証し、原本を退避したうえで元の場所へ書き戻します。作業先の設定や履歴は保存せず、正常終了後は一時ファイルと復旧記録を削除します。中断時は退避データを残し、キューから復旧できます。
- 音楽と時計を両方オフにした場合、ファイルをドラッグしていないときはノッチが広がらないように修正しました。

外付け作業中はディスクを接続したままにしてください。必要容量は目安です。APFSのスナップショットなどにより空きが増えない場合は、原本を外付けに残して復旧待ちになります。元フォルダやディスクのマウント位置を変更した場合の自動復旧には対応していません。

今回は実メディア処理を含む119件の自動テストと、ディスクイメージによる別ボリュームへの書き戻しを確認しています。物理外付けディスクでの許可表示・抜き差しの確認は未実施です。

Apple Silicon・macOS 14以降に対応。日本語・英語のDMGには同じアプリが入っています。
