# NotchCompressor 0.2.0

画像・音声の圧縮と、時計・Apple Musicのノッチ表示を追加しました。

- JPEG・PNG・AAC音声のM4Aに対応。動画とまとめて追加でき、ファイルの種類に合わせたドロップ領域が開きます。
- JPEGの品質、単体音声のビットレートを個別に設定できます。PNGは画素と透過を保って最適化します。
- ノッチにカーソルを合わせると時計やApple Musicの曲名・アルバム画像を表示。再生・一時停止も操作できます。時計と音楽はそれぞれ非表示・ホバー時・常時表示を選べます。
- 設定画面を整理し、詳しい説明をⓘに集約。対応するmacOSではLiquid Glassの選択ボタンを使います。
- 常時表示の幅に合わせてノッチが開閉するよう改善しました。
- 通知が許可されていない場合の案内を改善。新規インストールの自動更新チェックを有効にしました。既存設定は維持します。

## インストール

macOS 14以降・Apple Silicon向け。`-ja.dmg` または `-en.dmg` を開き、アプリをApplicationsへドラッグしてください。案内の言語だけが異なり、アプリ本体は同じです。アプリとDMGはDeveloper ID署名・Apple公証済みです。0.1.0からはアプリ内の更新確認も利用できます。

## 対応範囲と保存

動画はMOV・MP4・M4V、画像はJPEG・PNG、音声はAACのM4Aに対応します。画像は128 MB・32メガピクセルまで。APNG・HEIF・HDR画像や、ALAC・WAV・MP3は今回の対象外です。M4Aは単一のモノラル／ステレオAACトラックが対象で、保持できないメタデータ等がある場合は原本を残します。音楽表示はApple Musicに対応します。

**出力を検証し、容量が減った場合だけ同じ場所の元ファイルを置き換えます。置き換え前のファイルは残りません。必要な原本は別に保存してください。** 失敗・キャンセル・削減なしの場合は原本を保持します。
