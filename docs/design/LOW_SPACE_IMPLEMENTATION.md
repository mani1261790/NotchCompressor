# 省容量モード実装計画

2026-11-27。永続的なディスク登録・許可一覧・選択履歴は作らない。

1. **容量確認と候補選択**：実空き容量を優先し、別の容量プールに属する書き込み可能な外付け候補を探す。開始時に再確認。選択はメモリ内のみ。
2. **外付け出力と原本保護**：通常の圧縮・検証を外付け作業領域で行う。小さくできた場合だけ退避原本を検証・同期保存し、復旧記録を書いてから元の場所を空ける。元の場所へコピー・検証後に確定。
3. **キューと復旧**：省容量処理は単独実行。切断・キャンセル・再起動後は一時記録から復旧できる。唯一の原本を通常のクリーンアップで消さない。完了時に一時記録を削除。
4. **日英UIと通知**：容量不足タスクの「外付けを使う」から容量確認済みのディスクを提示。「別のディスクを選ぶ」「今はしない」を用意。通知無効でもキューから操作可能。
5. **検証**：通常終了・削減なし・退避前の失敗・原本削除後の失敗・復旧・復旧先競合・容量変化・候補の同一ディスク拒否・記録の削除・キューの直列化・日英カタログを検証する。

公開配布とインストール済みアプリへの反映は、実装・検証の結果と区別して記録する。実機外付けや切断試験を未実施のまま検証済みとはしない。

## 実装・検証結果（2026-11-27）

- 容量不足通知とキューから、一時的な外付け作業先を選択する日英の画面を実装。候補表示・選択確定・タスク開始時に容量を確認し、実際の書き込み可否も確認する。
- 選択したディスクは当該タスクのメモリ内だけに保持。設定・ブックマーク・許可済みディスク一覧・選択履歴は追加していない。
- 原本、圧縮済みファイル、書き戻しのコピーをSHA-256で照合。原本を削除する前に、外付けの原本コピーとローカル／外付け双方の復旧記録を同期保存する。
- 完了時は外付けの作業領域と一時復旧記録を削除。復旧が未完了のときは原本コピーと記録を残し、キューから復旧可能。復旧先に別内容のファイルがある場合は上書きしない。
- 省容量タスクと復旧操作は、他の圧縮タスクと同時に実行しない。APFSで容量を共有する候補、容量不明・読み取り専用・ディスクイメージの候補は使用しない。
- 通常／実メディアを含む全111テスト成功（スキップなし）。新設の省容量テスト8件には、障害注入、元ファイル競合、記録削除途中の復旧、キュー直列化、選択非永続化、HFS+ディスクイメージを使った別ボリュームへの書き込みを含む。
- 日英379キーの一致、参照解決、差分の空白チェックを確認。

### 配布前の残り

実物の外付けディスクは接続されていないため、実機での候補表示・macOSのリムーバブルボリューム許可・抜き差し・再起動復旧と、選択画面／通知の操作確認は未実施。インストール済みアプリや公開リリースには未反映。

### 制約

必要量は見積もりであり、他アプリの書き込みやAPFSスナップショットによって実空き容量は変わる。原本退避後に元のボリュームの容量が増えない場合、原本を外付けに保護して復旧待ちにする。外付けディスクのマウント位置や元フォルダを変更した場合は自動復旧できない。通常モードの複数ジョブ間に容量予約を導入したものではない。
